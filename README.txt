V2Ray Shop Bot - Milestone 1

FIRST TIME
1. Double-click setup.bat
2. Paste your BotFather token
3. Double-click run.bat
4. Send /start to the bot
5. Send the /claimadmin CODE shown by setup.bat

NORMAL USE
Double-click run.bat

- Aiogram bot skeleton
- Long polling
- SQLite database
- /start, /cancel, /whoami
- Main menu + Home navigation
- Admin authorization + one-time admin claim
- Persistent admin/user data
- Safe .env handling
- setup.bat and run.bat
